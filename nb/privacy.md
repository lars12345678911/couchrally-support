# Personvern i CouchRally

Oppdatert 30. september 2026. Gjelder CouchRally for Apple TV.

[English](../privacy.md) · [Español](../es/privacy.md) · [Norsk bokmål](privacy.md)

## I appen

CouchRally krever ingen egen konto og inneholder ikke reklame, analyseverktøy eller sporingskode. Appen sender ikke spillaktivitet, kortvalg eller poeng til utvikleren. Språk- og lydvalg lagres lokalt på Apple TV-en. Poeng og pågående spill finnes bare i spilløkten og lagres ikke som en spillerhistorikk.

## Kjøp

Apple håndterer det valgfrie kjøpet av hele samlingen. CouchRally bruker Apples StoreKit til å kontrollere om Apple-kontoen har en verifisert rettighet til innholdet. Appen mottar ikke kortopplysninger og sender ikke kjøpskvitteringer til en utviklerserver. Apple behandler kjøp og tilhørende informasjon etter sin egen [personvernerklæring](https://www.apple.com/legal/privacy/).

## Support

Hvis du sender e-post til support, mottar Lars Ask opplysningene du velger å sende, og bruker dem til å svare og undersøke problemet. Ta bare med det som er nødvendig. Ikke send passord, betalingsopplysninger eller fullstendige kvitteringer. Du kan bruke samme adresse til å spørre om en supportmelding eller be om at den slettes. Denne kontakten er atskilt fra selve spillingen.

## Dokumentasjon på GitHub

Når du leser dokumentene på GitHub, omfattes besøket av [GitHubs personvernerklæring](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). GitHub kan behandle kontoinformasjon og tekniske besøksdata. Hvis GitHub Pages aktiveres, logger GitHub besøkendes IP-adresser for sikkerhetsformål. Dokumentene legger ikke til analyseverktøy eller sporingskode.
