# Privacidad de CouchRally

Actualizado el 30 de septiembre de 2026. Se aplica a CouchRally para Apple TV.

[English](../privacy.md) · [Español](privacy.md) · [Norsk bokmål](../nb/privacy.md)

## En la aplicación

CouchRally no requiere una cuenta propia ni contiene publicidad, herramientas de analítica o código de seguimiento. No envía al desarrollador las partidas, las tarjetas elegidas ni las puntuaciones. Las preferencias de idioma y sonido se guardan en el Apple TV. Las puntuaciones y la partida actual solo se mantienen durante esa sesión; no se guardan como un historial del jugador.

## Compras

Apple gestiona la compra opcional del juego completo. CouchRally usa StoreKit de Apple para comprobar si la Cuenta de Apple tiene un derecho verificado al contenido. La aplicación no recibe los datos de tu tarjeta ni envía recibos de compra a un servidor del desarrollador. Apple procesa las compras y los datos relacionados según su [política de privacidad](https://www.apple.com/legal/privacy/).

## Soporte

Si escribes a soporte, Lars Ask recibe la información que decides enviar y la utiliza para responder e investigar el problema. Incluye solo lo necesario. No envíes contraseñas, datos de pago ni recibos completos. Puedes usar la misma dirección para consultar sobre un mensaje de soporte o solicitar su eliminación. Esta comunicación es independiente del juego.

## Documentación en GitHub

Cuando consultas estos documentos en GitHub, la visita está sujeta a la [declaración de privacidad de GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). GitHub puede tratar datos de cuenta y datos técnicos de las visitas. Si se activa GitHub Pages, GitHub registra las direcciones IP por motivos de seguridad. Los documentos no añaden herramientas de analítica ni código de seguimiento.
