# CouchRally support

[English](support.md) · [Español](es/support.md) · [Norsk bokmål](nb/support.md)

Help with CouchRally, the party game for Apple TV with tvOS 17 or later. Play with four or more people, two to four teams and one Siri Remote. The game includes 14 languages; this support documentation is available in English, Spanish and Norwegian Bokmål.
